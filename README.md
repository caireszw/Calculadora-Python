# Calculadora-Python

Uma calculadora de terminal desenvolvida em Python para praticar lógica de programação, modularização e manipulação de arquivos.

## Funcionalidades

- Soma
- Subtração
- Multiplicação
- Divisão
- Histórico de operações
- Limpeza de histórico
- Interface simples via terminal

## Tecnologias utilizadas

- Python 3
- Manipulação de arquivos `.txt` / `.log`
- Estruturas condicionais e de repetição
- Modularização com funções e arquivos separados
